Important

HoldOveric is provided for information and training. It does not replace the current holdover time guidelines or the operator’s approved ground icing program, which always take precedence. The pilot in command remains responsible for establishing the holdover time and for the condition of the aircraft at takeoff.

Privacy Policy

Last updated: 1 October 2026

This policy describes what the app does with data. It is short because the app does very little with it.

What is collected

Nothing. The app has no user accounts, no analytics, no advertising, no crash reporting and no server of its own. Nothing is sent to the developer.

What is stored, and where

Everything the app holds is stored on the device itself, inside the app’s own storage area:

  • the selected fluid, procedure and aircraft category, so they are ready the next time
  • the last airport code entered and a running holdover-time timer
  • the treatment log: for each started timer, the time, airport, METAR, outside air temperature, conditions, fluid and holdover time

This data is removed when the app is deleted, and is included in the device’s own backups if the user has those switched on. Log entries can be deleted in the app at any time.

What is transmitted

  • Weather reports. When the user asks for a METAR, and every ten minutes while a holdover timer runs with the app open, the app requests the latest report for the entered airport from aviationweather.gov, a public service of the U.S. National Weather Service. Only the airport code is sent. Like any website, that service receives the device’s IP address with the request; its own privacy policy applies to it.
  • Apple Watch. A running holdover time is passed to the user’s own paired Apple Watch through Apple’s WatchConnectivity link between the two devices.

The app does not use location services. Day or night at an airport is calculated on the device from the airport coordinates built into the app. Reminders when a holdover time runs out are local notifications created on the device.

Sharing

The user can share a result as text or export the treatment log as a CSV file. Where that then goes is entirely the user’s own action — the app only hands it to the system share sheet.

Children

The app is a professional tool for flight crews and is not directed at children. It collects no data from anyone, of any age.

Changes to this policy

If the app ever starts doing something else with data, this page will say so before that version is released.
